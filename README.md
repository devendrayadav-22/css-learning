## 🎯 Purpose

The main purpose of this repository is to:

- Learn CSS from the basics.
- Practice different CSS properties and concepts.
- Understand how CSS styles HTML elements.
- Improve web design and styling skills.
- Build a strong foundation in frontend development.

## 🛠️ Technologies Used

- **HTML5** – To create the structure of web pages.
- **CSS3** – To style and design web pages.

## 🚀 How to Use

1. Clone this repository:

   ```bash
   git clone https://github.com/devendrayadav-22/css-learning.git
   ```

2. Open the project folder in VS Code.

3. Navigate to any practice folder (`01_practice`, `02_practice`, etc.).

4. Open the `index.html` file in your browser to see the practice.
